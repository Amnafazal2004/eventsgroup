Event Groups – Frontend

Live Demo: https://eventsgroup-rust.vercel.app/

### Overview

Event Groups is a frontend web application that allows users to explore  events, view details, and interact with event-related content. It is designed to provide a simple and clean interface for discovering and engaging with different events.

### Features
- Browse and search events
- View event details and information
- User-friendly and responsive UI
- Event listings with basic interaction

### Tech Stack
- HTML, CSS, JavaScript, Tailwind CSS 
- React, Next.js 

### Project Type
This is a frontend-only project with no backend integration.

Getting Started
```
git clone <your-repo-link>
cd project-folder
npm install
npm run dev
```

### Deployment
The project is deployed on Vercel for fast and easy hosting.
